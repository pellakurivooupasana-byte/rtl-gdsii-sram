# SRAM Controller | RTL-to-GDSII using OpenLane

## Overview

This project implements a Static Random Access Memory (SRAM) Controller in Verilog HDL and demonstrates the complete RTL-to-GDSII ASIC design flow using OpenLane with the SKY130 PDK.

## Features

- SRAM Read Operation
- SRAM Write Operation
- Address and Data Bus Interface
- Memory Control Logic
- Functional Verification using ModelSim
- RTL-to-GDSII Implementation using OpenLane

## Tools Used

- Verilog HDL
- ModelSim
- OpenLane
- OpenROAD
- Yosys
- Magic
- KLayout
- SKY130 PDK
